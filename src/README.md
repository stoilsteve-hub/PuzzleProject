# PuzzleProject — 15 Puzzle Game (Java Swing)


##  Assignment Summary

This project creates a **15-puzzle** game in Java.  
The puzzle consists of 15 numbered tiles arranged in a 4 × 4 grid with one empty spot.  
You can slide tiles into the empty spot to arrange them back into order.

---

##  Features (Pass – G)

- Graphical interface with a 4×4 grid of numbered tiles.
- Click a tile **next to the empty space** to move it.
- Clicking a tile that is **not adjacent** does nothing.
- **“Start/Refresh Game”** button to shuffle the tiles randomly.
- Displays a **“Congratulations, you won!”** message when solved.
